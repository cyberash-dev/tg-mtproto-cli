# Topic

Доменная сущность forum-топика в супергруппе.

## Поля

| Поле | Тип | Описание |
|---|---|---|
| id | number | ID топика (уникален в пределах чата) |
| title | string | Название топика |
| unreadCount | number | Количество непрочитанных сообщений |
| isClosed | boolean | Закрыт ли топик |
| isPinned | boolean | Закреплён ли топик |

## Бизнес-правила

- Topic существует только в супергруппах с включённым режимом форума.
- `id = 1` — всегда General-тема (создаётся автоматически при включении форума).
- Закрытый топик (`isClosed = true`) — в него нельзя писать, но можно читать сообщения.
