# Accounts List

Выводит список всех залогиненных аккаунтов.

## Команда CLI

```bash
tg accounts
```

## Входные параметры

Нет.

## Выходные данные

Таблица аккаунтов:

```
  #  Alias       Phone            Name              Default
  1  work        +79001234567     Иван Иванов       *
  2  personal    +79007654321     Пётр Петров        
```

В JSON-режиме (`--json`):

```json
[
  {
    "id": 123456789,
    "phone": "+79001234567",
    "firstName": "Иван",
    "lastName": "Иванов",
    "username": "ivanov",
    "alias": "work",
    "isDefault": true
  }
]
```

## Основной сценарий

1. Получить список всех аккаунтов из CredentialStorage.
2. Отформатировать и вывести таблицу.

## Ошибки

| Ситуация | Сообщение | Exit code |
|---|---|---|
| Нет залогиненных аккаунтов | `No accounts found. Use 'tg auth' to log in.` | 0 |

## Граничные случаи

- Пустой список: вывести информационное сообщение вместо пустой таблицы.
- Аккаунт без lastName: отобразить только firstName.
